# 环境准备 · 迁移 CRD 存储版本并保留对象

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择 Docker、Podman 或 nerdctl。在仓库根目录进入本题目录，随后用下列命令创建集群。已有同名 kind 集群时可以跳过创建。

```sh
cd 31_迁移CRD存储版本并保留对象
kind create cluster --name cka-next --config kind-config.yaml --wait 5m
```

本目录的 [kind-config.yaml](kind-config.yaml) 定义节点布局。[crd.yaml](crd.yaml) 提供双版本 CRD，两版本使用相同 schema。

用 [setup.yaml](setup.yaml) 建立初始资源，再核对初始状态。

```sh
kubectl config use-context kind-cka-next
kubectl --context kind-cka-next apply -f crd.yaml
kubectl --context kind-cka-next wait --for=condition=Established crd/schedules.practice.cka.example --timeout=60s
kubectl --context kind-cka-next get --raw=/apis/practice.cka.example/v1beta1 >/dev/null
kubectl --context kind-cka-next apply -f setup.yaml
kubectl -n cka-31 get schedules.v1beta1.practice.cka.example
kubectl get crd schedules.practice.cka.example -o jsonpath='{.status.storedVersions}{"\n"}'
```

重练前在 `kind-cka-next` 删除本题专用 CRD `schedules.practice.cka.example`，这也会删除此类型的练习对象。再执行准备步骤。
