# 第 24 题 · 解题思路

## 关键技术难点

多容器 Pod 必须选择正确容器。CrashLoopBackOff 是重启等待状态，最近一次退出码在容器状态的 lastState 中。把文件保存到本机的重定向应写在 kubectl 命令外层。

## 解题顺序与答案详解

等待业务容器至少重启一次，在触发 rollout 前保留证据。若当前尚无 previous 容器，用 `kubectl -n cka-24 describe pods -l app=reporter` 查看状态后重试。

```sh
pod=$(kubectl -n cka-24 get pod -l app=reporter -o jsonpath='{.items[0].metadata.name}')
kubectl -n cka-24 logs "$pod" -c reporter --previous > reporter.previous.log
kubectl -n cka-24 get pod "$pod" -o jsonpath='{.status.containerStatuses[?(@.name=="reporter")].lastState.terminated.exitCode}{"\n"}' > reporter.exit-code
kubectl -n cka-24 patch cm settings --type=merge -p '{"data":{"REPORT_MODE":"live"}}'
kubectl -n cka-24 rollout restart deployment/reporter
kubectl -n cka-24 rollout status deploy/reporter --timeout=120s
```

更新 ConfigMap 后触发 rollout，使新 Pod 可靠地载入环境变量。

对照[题面验收标准](题目.md)检查最终状态。
