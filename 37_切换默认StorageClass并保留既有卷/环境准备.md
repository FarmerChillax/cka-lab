# 环境准备 · 切换默认 StorageClass 并保留既有卷

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择可用的 Docker、Podman 或 nerdctl。先进入本题目录。已有 `cka-storage37` 集群时可跳过创建。

```sh
cd 37_切换默认StorageClass并保留既有卷
kind create cluster --name cka-storage37 --config kind-config.yaml --wait 5m
```

用 [kind-config.yaml](kind-config.yaml) 创建集群后，应用 [setup.yaml](setup.yaml) 并确认初始状态。

```sh
kubectl config use-context kind-cka-storage37
kubectl get storageclass standard
kubectl apply -f setup.yaml
kubectl -n cka-37 wait --for=condition=Ready pod/old-reader --timeout=180s
kubectl -n cka-37 exec old-reader -- sh -c 'echo before-switch > /data/marker'
kubectl -n cka-37 get pvc
```

本题使用独立的 `cka-storage37`。准备时 `standard` 须为唯一默认类，existing 应为 Bound，static-only 应为 Pending。

重练时用 `kind delete cluster --name cka-storage37` 删除本题独立集群，再用本页命令创建。
