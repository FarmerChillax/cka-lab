# 第 37 题 · 解题思路

## 关键技术难点

已经分配存储类的 PVC 不会因为默认值变更而迁移。省略字段的新 PVC 可获得默认值，显式空字符串则 opt out。延迟绑定类需要消费者触发动态供应。

## 解题思路与答案详解

先取消旧默认，再设置新默认。本题在独立的 kind 集群进行，短暂没有默认类不会影响其他练习。

```sh
kubectl annotate storageclass standard storageclass.kubernetes.io/is-default-class=false --overwrite
kubectl annotate storageclass standard-next storageclass.kubernetes.io/is-default-class=true --overwrite
kubectl get storageclass
```

将以下资源保存为 `fresh.yaml` 并应用。

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: fresh
  namespace: cka-37
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: 64Mi
---
apiVersion: v1
kind: Pod
metadata:
  name: fresh-reader
  namespace: cka-37
spec:
  containers:
  - name: reader
    image: busybox:1.36
    command: ["sleep", "infinity"]
    volumeMounts:
    - name: data
      mountPath: /data
  volumes:
  - name: data
    persistentVolumeClaim:
      claimName: fresh
```

```sh
kubectl apply -f fresh.yaml
kubectl -n cka-37 wait --for=condition=Ready pod/fresh-reader --timeout=180s
kubectl -n cka-37 get pvc fresh
```

若 fresh Pending，查看 PVC 与 Pod 事件，检查默认注解是否正确、消费者是否被调度，以及 local-path provisioner 是否就绪。

按[题面验收标准](题目.md)检查结果。
