# 第 26 题 · 解题思路

## 关键技术难点

OnDelete 模式下更新模板不会替换旧 Pod。务必等前一个节点的新 Pod Ready 再替换下一个，单次删除只作用于该节点上的一个实例。

## 解题顺序与答案详解

更新模板后逐个按节点选择旧 Pod。先等待旧 Pod 删除，再按节点与标签等待新 Pod 出现并就绪。

```sh
kubectl -n cka-26 set env ds/node-observer OBSERVATION_MODE=detailed
for node in cka-next-worker cka-next-worker2; do
  kubectl -n cka-26 delete pod -l app=node-observer --field-selector "spec.nodeName=$node" --wait=true
  kubectl -n cka-26 wait --for=create pod -l app=node-observer --field-selector "spec.nodeName=$node" --timeout=120s || break
  kubectl -n cka-26 wait --for=condition=Ready pod -l app=node-observer --field-selector "spec.nodeName=$node" --timeout=120s || break
done
```

如果中途失败，先查看新 Pod 的调度事件与容器状态，再继续下一节点。
