# 第 35 题 · 解题思路

## 关键技术难点

使用单独的区域块，使练习域与处理集群域和外部转发的现有根区域块各自保留。验证要走 Pod 的实际 DNS 配置。

## 解题思路与答案详解

执行 `kubectl -n kube-system edit configmap coredns`，在 `data.Corefile` 多行文本内、现有根区域的闭合括号之后，追加以下内容。缩进与现有 Corefile 内容对齐。

```text
lab35.test:53 {
    errors
    hosts {
        192.0.2.35 docs.lab35.test
    }
}
```

重启并等待新版 CoreDNS，再从探测 Pod 验证。

```sh
kubectl -n kube-system rollout restart deployment/coredns
kubectl -n kube-system rollout status deployment/coredns --timeout=120s
kubectl -n cka-35 exec dns-probe -- nslookup docs.lab35.test.
kubectl -n cka-35 exec dns-probe -- nslookup kubernetes.default.svc.cluster.local.
```

新 Pod 无法 Ready 时查看 `kubectl -n kube-system logs -l k8s-app=kube-dns`，重点检查 Corefile 的括号和缩进。

按[题面验收标准](题目.md)检查结果。
