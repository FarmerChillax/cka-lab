# 第 35 题 · 为 CoreDNS 配置内部静态域名

建议用时 20 分钟。准备完成后开始计时。

操作入口 `kubectl config use-context kind-cka-dns35`，命名空间 `cka-35`。

## 题目主干

在集群 DNS 中加入练习域 `lab35.test`，使所有使用集群 DNS 的 Pod 可把 `docs.lab35.test` 解析为 IPv4 地址 `192.0.2.35`。仅修改 `kube-system/coredns` ConfigMap 的 Corefile，可重启 CoreDNS Deployment。保持原有集群域记录和默认转发行为，禁止在客户端写 `/etc/hosts`。目标地址是占位地址，验收仅查询 DNS。

## 官方参考

- [Customizing DNS Service](https://kubernetes.io/docs/tasks/administer-cluster/dns-custom-nameservers/) · CoreDNS ConfigMap、Corefile 与集群域。
- [CoreDNS hosts 插件](https://coredns.io/plugins/hosts/) · 在指定区域提供静态地址记录。

## 验收标准

```sh
kubectl -n cka-35 exec dns-probe -- nslookup docs.lab35.test.
kubectl -n cka-35 exec dns-probe -- nslookup kubernetes.default.svc.cluster.local.
kubectl -n kube-system rollout status deployment/coredns --timeout=120s
```

第一条解析到 `192.0.2.35`，第二条仍返回 `default/kubernetes` Service 的 ClusterIP，CoreDNS 就绪。
