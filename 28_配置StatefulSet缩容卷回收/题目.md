# 第 28 题 · 配置 StatefulSet 缩容卷回收

建议用时 20 分钟，环境准备完成后开始计时。

操作入口 `kubectl config use-context kind-cka-next`。Context 为 `kind-cka-next`，命名空间为 `cka-28`。

## 题目主干

配置 StatefulSet `journal`，使缩容自动删除被缩掉副本的 PVC，删除 StatefulSet 时保留仍关联的 PVC。缩容到 1 后，证明 `data-journal-1` 已删除且 ordinal 0 的数据仍在。然后恢复到 2 个副本，证明重建的 ordinal 1 没有旧标记。

## 官方参考

- [StatefulSet PVC retention](https://kubernetes.io/docs/concepts/workloads/controllers/statefulset/#persistentvolumeclaim-retention) · 区分缩容和删除时的 PVC 策略。
- [Storage Classes](https://kubernetes.io/docs/concepts/storage/storage-classes/) · 动态供应与 PV 回收策略。

## 验收标准

```sh
kubectl -n cka-28 get sts journal -o jsonpath='{.spec.persistentVolumeClaimRetentionPolicy}{"\n"}'
kubectl -n cka-28 get pvc
kubectl -n cka-28 exec journal-0 -- cat /data/id
kubectl -n cka-28 exec journal-1 -- test ! -e /data/id
```

最终两个 PVC Bound，ordinal 0 输出 journal-zero，最后一条成功。缩容阶段需确认 data-journal-1 消失。
