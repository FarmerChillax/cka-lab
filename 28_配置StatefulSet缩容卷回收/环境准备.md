# 环境准备 · 配置 StatefulSet 缩容卷回收

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择 Docker、Podman 或 nerdctl。在仓库根目录进入本题目录，随后用下列命令创建集群。已有同名 kind 集群时可以跳过创建。

```sh
cd 28_配置StatefulSet缩容卷回收
kind create cluster --name cka-next --config kind-config.yaml --wait 5m
```

本目录的 [kind-config.yaml](kind-config.yaml) 定义节点布局。本题使用标准 kind 集群附带的 standard StorageClass。旧题对其他集群的默认 StorageClass 调整不会作用到 cka-next。

用 [setup.yaml](setup.yaml) 建立初始资源，再核对初始状态。

```sh
kubectl config use-context kind-cka-next
kubectl --context kind-cka-next apply -f setup.yaml
kubectl get storageclass standard
kubectl -n cka-28 rollout status sts/journal --timeout=180s
kubectl -n cka-28 exec journal-0 -- sh -c 'echo journal-zero > /data/id'
kubectl -n cka-28 exec journal-1 -- sh -c 'echo journal-one > /data/id'
kubectl -n cka-28 get pvc
```

如需重练，先执行 `kubectl --context kind-cka-next delete namespace cka-28 --ignore-not-found --wait=true`，随后重新运行本页准备命令。该命名空间只用于本题。
