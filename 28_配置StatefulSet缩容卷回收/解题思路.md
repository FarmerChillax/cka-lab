# 第 28 题 · 解题思路

## 关键技术难点

StatefulSet 的 PVC 保留策略决定何时删除 PVC。PVC 删除后底层 PV 的处理仍取决于 PV 回收策略。先改策略，再缩容并等待删除事件，避免在旧卷释放前扩回。

## 解题顺序与答案详解

保留 ordinal 1 旧 PVC 的 UID 作为对照。修改两类保留策略后按顺序操作。

```sh
kubectl -n cka-28 get pvc data-journal-1 -o jsonpath='{.metadata.uid}{"\n"}'
kubectl -n cka-28 patch sts journal --type=merge -p '{"spec":{"persistentVolumeClaimRetentionPolicy":{"whenDeleted":"Retain","whenScaled":"Delete"}}}'
kubectl -n cka-28 scale sts/journal --replicas=1
kubectl -n cka-28 wait --for=delete pvc/data-journal-1 --timeout=180s
kubectl -n cka-28 exec journal-0 -- cat /data/id
kubectl -n cka-28 scale sts/journal --replicas=2
kubectl -n cka-28 rollout status sts/journal --timeout=180s
kubectl -n cka-28 get pvc data-journal-1 -o jsonpath='{.metadata.uid}{"\n"}'
```

新 PVC 的 UID 应发生变化。若旧 PVC 迟迟不消失，查看 ordinal 1 是否还在 Terminating，然后检查 PVC 的 ownerReferences 和 finalizers。

对照[题面验收标准](题目.md)检查最终状态。
