# 环境准备 · 修复非 root 容器的共享卷写入

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择可用的 Docker、Podman 或 nerdctl。先进入本题目录。已有 `cka-next` 集群时可跳过创建。

```sh
cd 36_修复非root容器的共享卷写入
kind create cluster --name cka-next --config kind-config.yaml --wait 5m
```

用 [kind-config.yaml](kind-config.yaml) 创建集群后，应用 [setup.yaml](setup.yaml) 并确认初始状态。

```sh
kubectl config use-context kind-cka-next
kubectl apply -f setup.yaml
kubectl -n cka-36 wait --for=create pod -l app=spooler --timeout=60s
kubectl -n cka-36 wait --for=jsonpath='{.status.containerStatuses[?(@.name=="writer")].lastState.terminated.exitCode}' pod -l app=spooler --timeout=120s
kubectl -n cka-36 get pods
```

重练时执行 `kubectl --context kind-cka-next delete namespace cka-36 --ignore-not-found --wait=true`，再应用本题配置。
