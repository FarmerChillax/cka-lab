# 第 36 题 · 解题思路

## 关键技术难点

容器用户的主组与挂载卷的组是两个设置。对于本题的 emptyDir，kubelet 在容器启动前应用 fsGroup，随后初始化容器在带 setgid 的卷根目录下创建子目录，子目录继承卷的组。

## 解题思路与答案详解

先查看 writer 日志，确认失败发生在写文件时。将组设置到 Pod 模板，等待新 Pod 使用新建的 emptyDir。

```sh
kubectl -n cka-36 describe pods -l app=spooler
kubectl -n cka-36 logs deploy/spooler -c writer --previous \
  || kubectl -n cka-36 logs deploy/spooler -c writer
```

日志中应能看到写入失败。若上次容器刚被替换，等下一次退出后重试日志命令。确认后修改模板。

```sh
kubectl -n cka-36 patch deploy spooler --type=merge \
  -p '{"spec":{"template":{"spec":{"securityContext":{"fsGroup":2000}}}}}'
kubectl -n cka-36 rollout status deployment/spooler --timeout=120s
```

若 `--previous` 尚无日志，查看当前日志或等待一次重启。若仍不可写，核对 `id` 的补充组和目录的数字 GID；仅为 writer 添加补充组不会改变卷的文件组归属。

按[题面验收标准](题目.md)检查结果。
