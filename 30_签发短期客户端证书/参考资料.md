# 第 30 题 · 题目出处与参考资料

本题依据 CKA 考纲中的 **Cluster Architecture, Installation & Configuration** 编写，是原创实操练习。kind 节点为本地容器，操作入口以本题为准。

- [Linux Foundation CKA 考纲](https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/) · 对应考核范围与 Kubernetes v1.37 考试版本。
- [Linux Foundation CKA 可用资料](https://docs.linuxfoundation.org/tc-docs/certification/certification-resources-allowed#certified-kubernetes-administrator-cka-and-certified-kubernetes-application-developer-ckad) · 正式考试的查阅规则。
- [kind 快速入门](https://kind.sigs.k8s.io/docs/user/quick-start/) · 本地环境准备。
- [Kubernetes CSR](https://kubernetes.io/docs/reference/access-authn-authz/certificate-signing-requests/) · 客户端 signer、审批和证书读取。
- [配置 kubeconfig](https://kubernetes.io/docs/tasks/access-application-cluster/configure-access-multiple-clusters/) · 独立凭据与上下文。
- [配置客户端证书](https://kubernetes.io/docs/tasks/tls/certificate-issue-client-csr/) · 从 CSR 申请 API 客户端证书。
