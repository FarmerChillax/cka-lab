# 第 34 题 · 恢复 CronJob 调度并验证一次性任务

建议用时 17 分钟。准备完成后开始计时。

操作入口 `kubectl config use-context kind-cka-next`，命名空间 `cka-34`。

## 题目主干

定时报表任务 `report-export` 当前暂停。恢复其调度并满足以下要求。

- 工作日 UTC 02:15 执行。上一次运行未结束时跳过本次。
- 错过计划时间超过 90 秒时，不再补跑。
- 保留最近 2 个成功 Job 和 1 个失败 Job。
- 从原模板触发名为 `report-export-smoke` 的一次性 Job。不得修改容器镜像、命令或直接等待下一个计划时间。

## 官方参考

- [CronJob](https://kubernetes.io/docs/concepts/workloads/controllers/cron-jobs/) · 时区、并发、超时和历史保留。
- [kubectl create job](https://kubernetes.io/docs/reference/kubectl/generated/kubectl_create/kubectl_create_job/) · 从 CronJob 模板运行一次。

## 验收标准

```sh
kubectl -n cka-34 get cronjob report-export -o yaml
kubectl -n cka-34 wait --for=condition=Complete job/report-export-smoke --timeout=120s
kubectl -n cka-34 logs job/report-export-smoke
```

CronJob 已启用，时间、并发、补跑与历史字段均符合要求。一次性 Job 的日志输出 `export-ok`。
