# 第 34 题 · 解题思路

## 关键技术难点

调度表达式按 CronJob 的时区解释。并发限制只约束同一 CronJob 控制器创建的 Job。手动 Job 可验证模板，但不代表调度器已执行过该时间表。

## 解题思路与答案详解

同时更新时区、补跑上限和暂停开关，再从新配置的 CronJob 创建一次性 Job。

```sh
kubectl -n cka-34 patch cronjob report-export --type=merge \
  -p '{"spec":{"schedule":"15 2 * * 1-5","timeZone":"Etc/UTC","suspend":false,"concurrencyPolicy":"Forbid","startingDeadlineSeconds":90,"successfulJobsHistoryLimit":2,"failedJobsHistoryLimit":1}}'
kubectl -n cka-34 create job report-export-smoke --from=cronjob/report-export
kubectl -n cka-34 wait --for=condition=Complete job/report-export-smoke --timeout=120s
kubectl -n cka-34 logs job/report-export-smoke
```

`Forbid` 跳过重叠执行，历史上限分别对成功与失败 Job 生效。Job 未完成时先查看它的 Pod 事件与日志。
