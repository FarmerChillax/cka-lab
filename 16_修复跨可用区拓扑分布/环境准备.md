# 环境准备：修复跨可用区拓扑分布

本题沿用三节点 `cka-lab` 集群。若集群不存在，在本目录执行：

```sh
kind create cluster --name cka-lab --config kind-config.yaml --wait 5m
```

为两个工作节点设置不同的区域标签，然后应用初始资源：

```sh
kubectl config use-context kind-cka-lab
kubectl label node cka-lab-worker topology.kubernetes.io/zone=zone-a --overwrite
kubectl label node cka-lab-worker2 topology.kubernetes.io/zone=zone-b --overwrite
kubectl uncordon cka-lab-worker cka-lab-worker2
kubectl delete namespace cka-topology --ignore-not-found
kubectl apply -f setup.yaml
kubectl -n cka-topology rollout status deployment/api
kubectl -n cka-topology get pods -o wide
```

初始 Deployment 没有拓扑分布约束，当前分布是否均匀不影响题目。重复练习时重新删除命名空间并应用 `setup.yaml`。
