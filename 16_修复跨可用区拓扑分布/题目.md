# 第 16 题：修复跨可用区拓扑分布

**建议用时：** 15 分钟。**Context：** `kind-cka-lab`。**命名空间：** `cka-topology`。

## 题目主干

Deployment `api` 有 4 个副本。两个工作节点分别标记为 `zone-a` 和 `zone-b`。为该 Deployment 配置强制拓扑分布，使 Pod 满足：

1. 按 `topology.kubernetes.io/zone` 分布；
2. 两个区域之间的最大偏差 `maxSkew` 为 1；
3. 无法满足约束时保持 Pending，不得违反约束调度；
4. 只统计标签为 `app=api` 的 Pod；
5. 保持副本数、镜像和现有 Pod 标签不变。

完成后触发滚动更新，并使四个副本全部 Ready。

官方参考：

- https://kubernetes.io/docs/concepts/scheduling-eviction/topology-spread-constraints/

## 验收标准

```sh
kubectl -n cka-topology get deployment api -o yaml
kubectl -n cka-topology get pods -l app=api \
  -o custom-columns=NAME:.metadata.name,NODE:.spec.nodeName
```

预期 `topologySpreadConstraints` 中包含指定字段，四个 Pod 在两个区域中各有 2 个。
