# 环境准备：限定审计账号权限

本题沿用第 1 题的 `cka-lab` 集群。若单独练习本题，请先安装 `kind` v0.33.0 或更新版本、`kubectl`，并启动 kind 兼容容器运行时（如 Docker、Podman 或 nerdctl）。kind 默认自动选择可用运行时。在仓库根目录进入本题目录：

```sh
cd 02_限定审计账号权限
```

集群配置见 [kind-config.yaml](kind-config.yaml)。仅在集群不存在时执行：

```sh
kind create cluster \
  --name cka-lab --config kind-config.yaml --wait 5m
```

切换 context，并应用本题的 [setup.yaml](setup.yaml)。该清单可重复应用：

```sh
kubectl config use-context kind-cka-lab
kubectl apply -f setup.yaml
kubectl -n cka-lab get serviceaccount auditor
kubectl -n cka-lab get configmap runtime
```

环境准备完成后，开始本题的 10 分钟计时。若此前已经完成本题，重新练习前应在**练习集群**中移除先前创建的 `auditor` Role 和 RoleBinding，避免旧权限影响结果。
