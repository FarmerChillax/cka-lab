# 环境准备：批处理任务专用节点调度

本题沿用第 1 题的 `cka-lab` 集群。若单独练习本题，请先安装并启动 Podman、`kind` v0.33.0 或更新版本及 `kubectl`。在仓库根目录进入本题目录：

```sh
cd 03_批处理任务专用节点调度
```

集群配置见 [kind-config.yaml](kind-config.yaml)。仅在集群不存在时执行：

```sh
KIND_EXPERIMENTAL_PROVIDER=podman kind create cluster \
  --name cka-lab --config kind-config.yaml --wait 5m
```

应用 [setup.yaml](setup.yaml) 创建命名空间，并准备专用节点：

```sh
kubectl config use-context kind-cka-lab
kubectl apply -f setup.yaml
kubectl get nodes
kubectl label node cka-lab-worker2 workload=batch --overwrite
kubectl taint node cka-lab-worker2 dedicated=batch:NoSchedule --overwrite
kubectl describe node cka-lab-worker2
```

确认 `cka-lab-worker2` 为 Ready，具有 `workload=batch` 标签和 `dedicated=batch:NoSchedule` 污点。此时不要创建 Job；环境准备完成后，开始本题的 13 分钟计时。若此前已经完成本题，重新练习前应在**练习集群**中删除旧的 `batch-report` Job。
