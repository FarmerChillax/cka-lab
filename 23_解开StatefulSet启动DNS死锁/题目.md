# 第 23 题 · 解开 StatefulSet 启动 DNS 死锁

建议用时 18 分钟，环境准备完成后开始计时。

操作入口 `kubectl config use-context kind-cka-next`。Context 为 `kind-cka-next`，命名空间为 `cka-23`。

## 题目主干

StatefulSet `peer` 的第一个实例无法完成初始化。恢复两个副本，使每个 Pod 能在启动时解析自己的稳定域名。保留有序管理、初始化逻辑、Headless Service 名称和副本数。

## 官方参考

- [DNS for Services and Pods](https://kubernetes.io/docs/concepts/services-networking/dns-pod-service/) · Headless Service 的 Pod 域名与地址发布。
- [StatefulSets](https://kubernetes.io/docs/concepts/workloads/controllers/statefulset/) · 有序创建与稳定网络标识。

## 验收标准

```sh
kubectl -n cka-23 rollout status sts/peer --timeout=180s
kubectl -n cka-23 exec probe -- nslookup peer-0.peer.cka-23.svc.cluster.local
kubectl -n cka-23 exec probe -- nslookup peer-1.peer.cka-23.svc.cluster.local
```

两个查询应分别返回对应 Pod 地址，StatefulSet 达到 2/2 Ready。
