# 第 23 题 · 解题思路

## 关键技术难点

默认情况下，单个 Pod 的 DNS 记录依赖就绪端点，而这里初始化容器等待自己的记录。两个条件形成循环依赖。

## 解题顺序与答案详解

查看 `kubectl -n cka-23 logs peer-0 -c discover-self`，确认初始化还在等待 DNS 记录。为 governing Service 发布未就绪地址。

```sh
kubectl -n cka-23 patch svc peer --type=merge -p '{"spec":{"publishNotReadyAddresses":true}}'
kubectl -n cka-23 rollout status sts/peer --timeout=180s
```

若仍未恢复，等待 CoreDNS 负缓存过期，再核对 Pod 的 subdomain、命名空间和 Service selector。

对照[题面验收标准](题目.md)检查最终状态。
