# 第 6 题：回滚失败的 Deployment

**建议用时：** 15 分钟。**Context：** `kind-cka-lab`。**命名空间：** `cka-rollout`。

**操作入口：** `kubectl config use-context kind-cka-lab`

## 题目主干

`release-web` Deployment 最近一次镜像更新失败。检查其版本历史、ReplicaSet 和 Pod 状态，定位失败原因，并**回滚到上一个健康版本**。保留现有 Service、两个期望副本，以及滚动更新策略 `maxSurge: 1`、`maxUnavailable: 0`。不得通过删除并重建 Deployment 来完成任务。

## 题面引用信息

| 项目 | 给定值 |
| --- | --- |
| Deployment / Service | `release-web` / `release-web` |
| 命名空间 | `cka-rollout` |
| 期望副本数 | 2 |
| 允许的恢复方式 | 回滚到已有健康版本 |

官方参考：[Deployments](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/) 中的 **Rolling Back a Deployment**、**Rolling Update Deployment**；[`kubectl rollout`](https://kubernetes.io/docs/reference/kubectl/generated/kubectl_rollout/) 中的 `history`、`undo` 和 `status`。

## 验收标准

```sh
kubectl -n cka-rollout rollout status deployment/release-web --timeout=120s
kubectl -n cka-rollout get deployment release-web
kubectl -n cka-rollout get pods -l app=release-web
kubectl -n cka-rollout get deployment release-web \
  -o jsonpath='{.spec.template.spec.containers[0].image}{"\n"}'
kubectl -n cka-rollout get service release-web
```

Deployment 应为 `2/2`，两个当前 Pod 均 Ready，镜像恢复到上一个健康版本，Service 仍存在；滚动更新策略与副本数保持题面要求。
