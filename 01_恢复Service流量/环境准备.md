# 环境准备：恢复 Service 流量

需要 `kind` v0.33.0 或更新版本、`kubectl` 和已启动的 kind 兼容容器运行时（如 Docker、Podman 或 nerdctl）。kind 默认自动选择可用运行时。三节点集群建议给运行时至少 8 GiB 内存。

## 1. 创建集群（已有 `cka-lab` 时跳过）

在仓库根目录进入本题目录：

```sh
cd 01_恢复Service流量
```

集群配置已保存为 [kind-config.yaml](kind-config.yaml)。仅在集群不存在时执行：

```sh
kind version
kind create cluster \
  --name cka-lab --config kind-config.yaml --wait 5m
```

然后确认操作的是练习集群：

```sh
kubectl config use-context kind-cka-lab
kubectl get nodes
kubectl version
```

kind v0.33.0 默认使用 Kubernetes v1.37.0 节点镜像。本轮题目共用 `cka-lab` 集群，后续题目的环境准备无需重复创建集群。

## 2. 准备本题初始资源

初始资源已保存为 [setup.yaml](setup.yaml)，其中故意包含待排查故障。请勿在开始计时前修复。

```sh
kubectl apply -f setup.yaml
```

环境准备完成后，开始本题的 12 分钟计时。

环境配置依据见[参考资料](参考资料.md)。
