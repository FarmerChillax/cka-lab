# 第 1 题：恢复 Service 流量

**建议用时：** 12 分钟。**操作 context：** `kind-cka-lab`。**命名空间：** `cka-lab`。

**操作入口：** `kubectl config use-context kind-cka-lab`

## 题目主干

`catalog` Deployment 已创建两个 Pod，但 `catalog` Service 无法正常提供页面。找出并修复故障。不得删除 Service，也不得更改 Deployment 的副本数。

完成条件：两个 Pod 均为 Ready；从集群内访问 `http://catalog.cka-lab.svc.cluster.local` 能取得 Nginx 首页。

## 验收标准

保持 `catalog` Service 存在，Deployment 副本数仍为 2，并满足以下检查：

```sh
kubectl -n cka-lab rollout status deployment/catalog
kubectl -n cka-lab get deployment catalog
kubectl -n cka-lab get pods -l app=catalog
kubectl -n cka-lab get endpointslice \
  -l kubernetes.io/service-name=catalog
kubectl -n cka-lab run curl-check --rm -i --restart=Never \
  --image=busybox:1.36 -- \
  wget -qO- http://catalog.cka-lab.svc.cluster.local
```

预期 Deployment 为 `2/2`，两个 Pod 均 Ready，EndpointSlice 包含可用后端，最后一条命令输出 Nginx 首页。
