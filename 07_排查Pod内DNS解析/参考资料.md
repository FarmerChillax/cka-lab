# 第 7 题：题目出处与参考资料

本题依据 CKA 考纲的 **Services & Networking** 与 **Troubleshooting** 范围原创，并非官方真题。故障局限于练习命名空间中的客户端工作负载，不修改集群级 CoreDNS。

| 官方资料 | 对应内容 |
| --- | --- |
| [Linux Foundation CKA 考纲](https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/) | Pod 连通性、CoreDNS 和网络排障 |
| [DNS for Services and Pods](https://kubernetes.io/docs/concepts/services-networking/dns-pod-service/) | Service DNS 名称、命名空间搜索路径与 Pod DNS 策略 |
| [Pod API 参考](https://kubernetes.io/docs/reference/kubernetes-api/core/pod-v1/) | Pod 模板中的 `dnsPolicy` 与 `dnsConfig` 字段 |
| [kind 快速入门](https://kind.sigs.k8s.io/docs/user/quick-start/) | 运行时自动选择与多节点配置 |
