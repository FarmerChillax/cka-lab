# 第 10 题：解题思路与答案详解

## 关键技术难点

1. Ingress 只有在 `ingressClassName` 与已安装控制器匹配时才会被处理。
2. 更长的 `/api` Prefix 路径应与根路径同时存在，并可分别使用数字端口和具名端口。
3. TLS Secret 必须包含匹配的 `tls.crt`、`tls.key`，Ingress 的 `tls.hosts` 与规则主机应一致。

## 解题思路

先生成并检查证书，再用 `kubectl create secret tls` 创建标准 TLS Secret。随后编写一个同时包含 TLS、两条路径和重定向注解的 Ingress，最后从集群内绕过本机端口映射直接访问控制器 Service。

## 答案详解

```sh
openssl req -x509 -nodes -newkey rsa:2048 -days 30 \
  -keyout /tmp/portal.cka.local.key \
  -out /tmp/portal.cka.local.crt \
  -config tls/openssl.cnf
openssl x509 -in /tmp/portal.cka.local.crt -noout -subject -ext subjectAltName
kubectl -n cka-edge create secret tls portal-tls \
  --cert=/tmp/portal.cka.local.crt --key=/tmp/portal.cka.local.key
```

保存并应用 `portal-ingress.yaml`：

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: portal
  namespace: cka-edge
  annotations:
    nginx.ingress.kubernetes.io/ssl-redirect: "true"
spec:
  ingressClassName: nginx
  tls:
  - hosts:
    - portal.cka.local
    secretName: portal-tls
  rules:
  - host: portal.cka.local
    http:
      paths:
      - path: /api
        pathType: Prefix
        backend:
          service:
            name: api-svc
            port:
              number: 8080
      - path: /
        pathType: Prefix
        backend:
          service:
            name: web-svc
            port:
              name: http
```

```sh
kubectl apply -f portal-ingress.yaml
kubectl -n cka-edge describe ingress portal
```

运行题面验收命令。若返回默认 404，优先检查请求的 `Host`、`ingressClassName` 和规则主机；若出现 503，检查 Service 端口及 EndpointSlice；TLS 失败时检查 Secret 类型、键名和证书私钥是否匹配。
