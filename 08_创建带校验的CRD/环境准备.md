# 环境准备：创建带校验的 CRD

需要 `kind` v0.33.0 或更新版本、`kubectl` 和已启动的 kind 兼容容器运行时。kind 默认自动选择可用运行时。本题沿用 `cka-lab` 集群；已有集群时跳过创建。

从仓库根目录进入本题目录：

```sh
cd 08_创建带校验的CRD
```

集群配置见 [kind-config.yaml](kind-config.yaml)。仅在集群不存在时执行：

```sh
kind create cluster --name cka-lab --config kind-config.yaml --wait 5m
```

应用 [setup.yaml](setup.yaml) 创建练习命名空间，并确认尚无本题的 CRD。不要在准备阶段创建自定义资源或其定义。

```sh
kubectl config use-context kind-cka-lab
kubectl get nodes
kubectl apply -f setup.yaml
kubectl get namespace cka-ext
kubectl get crd widgets.lab.cka.example
```

最后一条命令预期输出 NotFound。开始本题的 20 分钟计时。

重练时先确认 context，再删除本题 CRD；这会同时删除其所有自定义对象，仅在练习集群执行。之后重新应用 `setup.yaml`：

```sh
kubectl config current-context
kubectl delete crd widgets.lab.cka.example --ignore-not-found
kubectl apply -f setup.yaml
```
