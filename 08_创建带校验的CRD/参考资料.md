# 第 8 题：题目出处与参考资料

本题依据 CKA 考纲 **Cluster Architecture, Installation & Configuration** 中的 CRD 扩展机制范围原创，并非官方真题。这里仅创建 API 类型和自定义对象；没有安装控制器或 operator，自定义对象不会自动生成 Deployment。

| 官方资料 | 对应内容 |
| --- | --- |
| [Linux Foundation CKA 考纲](https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/) | CRD 与集群扩展接口 |
| [CustomResourceDefinition](https://kubernetes.io/docs/tasks/extend-kubernetes/custom-resources/custom-resource-definitions/) | 结构化 schema、字段校验、`status` 子资源、打印列 |
| [Kubernetes API 扩展概念](https://kubernetes.io/docs/concepts/extend-kubernetes/api-extension/custom-resources/) | CRD 与自定义资源的关系 |
| [kind 快速入门](https://kind.sigs.k8s.io/docs/user/quick-start/) | 运行时自动选择与多节点配置 |
