# 环境准备 · 使用 Job 迁移 PVC 中的数据

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择 Docker、Podman 或 nerdctl。在仓库根目录进入本题目录，随后用下列命令创建集群。已有同名 kind 集群时可以跳过创建。

```sh
cd 29_使用Job迁移PVC中的数据
kind create cluster --name cka-next --config kind-config.yaml --wait 5m
```

本目录的 [kind-config.yaml](kind-config.yaml) 定义节点布局。使用 kind 提供的 standard StorageClass。目标 PVC 在被消费前可能保持 Pending。

用 [setup.yaml](setup.yaml) 建立初始资源，再核对初始状态。

```sh
kubectl config use-context kind-cka-next
kubectl --context kind-cka-next apply -f setup.yaml
kubectl -n cka-29 rollout status deploy/archive --timeout=180s
kubectl -n cka-29 exec deploy/archive -- sh -ec 'mkdir -p /data/nested; printf "quarterly-report\n" > /data/nested/report.txt; touch /data/.manifest'
kubectl -n cka-29 get pvc
```

如需重练，先执行 `kubectl --context kind-cka-next delete namespace cka-29 --ignore-not-found --wait=true`，随后重新运行本页准备命令。该命名空间只用于本题。
