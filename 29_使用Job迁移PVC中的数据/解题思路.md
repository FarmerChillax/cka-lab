# 第 29 题 · 解题思路

## 关键技术难点

两个卷由同一个 Job Pod 使用，调度器会根据已绑定的本地源卷选择节点，再给延迟绑定的目标卷分配同节点存储。复制源使用 /src/. 才会包括隐藏文件。

## 解题顺序与答案详解

先停止原应用。用以下 Job 清单执行复制，源卷在卷声明和容器挂载中都标为只读。

```sh
kubectl -n cka-29 scale deploy/archive --replicas=0
kubectl -n cka-29 wait --for=delete pod -l app=archive --timeout=120s
```

```yaml
apiVersion: batch/v1
kind: Job
metadata: {name: copy-archive, namespace: cka-29}
spec:
  backoffLimit: 2
  template:
    spec:
      restartPolicy: Never
      containers:
      - name: copy
        image: busybox:1.36
        command: [sh, -ec, 'cp -a /src/. /dst/; cmp /src/nested/report.txt /dst/nested/report.txt; test -f /dst/.manifest']
        volumeMounts:
        - {name: source, mountPath: /src, readOnly: true}
        - {name: destination, mountPath: /dst}
      volumes:
      - name: source
        persistentVolumeClaim: {claimName: source, readOnly: true}
      - name: destination
        persistentVolumeClaim: {claimName: destination}
```

保存为 `copy-archive.yaml`，再执行下列命令。若 Job 未完成，查看其 Pod 的调度事件与日志，暂缓切换卷。

```sh
kubectl apply -f copy-archive.yaml
kubectl -n cka-29 wait --for=condition=Complete job/copy-archive --timeout=180s
kubectl -n cka-29 patch deploy archive --type=strategic -p '{"spec":{"template":{"spec":{"volumes":[{"name":"store","persistentVolumeClaim":{"claimName":"destination"}}]}}}}'
kubectl -n cka-29 scale deploy/archive --replicas=1
kubectl -n cka-29 rollout status deploy/archive --timeout=180s
```

对照[题面验收标准](题目.md)检查最终状态。
