# 第 20 题 · 解题思路

## 关键技术难点

同命名空间的 HTTPRoute 可以绑定 Gateway。跨命名空间的后端引用还需要目标命名空间授权，来源按命名空间、组与 Kind 匹配。

## 解题顺序与答案详解

用 `kubectl -n cka-20 describe httproute reports` 检查父级状态中的 RefNotPermitted。将以下清单保存为 `reports-grant.yaml`。

```yaml
apiVersion: gateway.networking.k8s.io/v1beta1
kind: ReferenceGrant
metadata: {name: allow-reports, namespace: cka-20-backend}
spec:
  from:
  - {group: gateway.networking.k8s.io, kind: HTTPRoute, namespace: cka-20}
  to:
  - {group: "", kind: Service, name: reports}
```

```sh
kubectl --context kind-cka-gateway apply -f reports-grant.yaml
```

若条件已恢复但请求失败，继续核对 Host、代理 Pod 就绪状态和后端 EndpointSlice。

对照[题面验收标准](题目.md)检查最终状态。
