# 环境准备：使用 Helm 完成安装与升级

需要 `helm`、`kubectl` 和现有 `cka-lab` 集群。若集群不存在，在本目录执行：

```sh
kind create cluster --name cka-lab --config kind-config.yaml --wait 5m
```

在本题目录准备环境：

```sh
kubectl config use-context kind-cka-lab
kubectl apply -f setup.yaml
helm uninstall reporting -n cka-helm 2>/dev/null || true
helm lint ./chart
helm template reporting ./chart -n cka-helm >/dev/null
```

开始前应确认 `helm list -n cka-helm` 中没有 `reporting`。本地 chart 已保存在 `chart/`，不得在准备阶段安装 release。
