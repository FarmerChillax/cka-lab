# 第 15 题：使用 Helm 完成安装与升级

**建议用时：** 16 分钟。**Context：** `kind-cka-lab`。**命名空间：** `cka-helm`。

## 题目主干

使用本题目录中的 Helm chart `./chart` 管理应用：

1. 安装 release `reporting`，第一次安装使用 chart 默认值，并等待资源 Ready。
2. 将同一 release 升级到第二个 revision，最终配置为：
   - 副本数 2；
   - 镜像 `nginx:1.27.5`；
   - Service 类型 `ClusterIP`；
   - Service 端口 8080，容器目标端口保持 80。
3. 必须通过 Helm values 完成配置，不得直接编辑 Helm 创建的 Deployment 或 Service。
4. 保留两个 revision 的历史。

官方参考：

- https://helm.sh/docs/helm/helm_install/
- https://helm.sh/docs/helm/helm_upgrade/
- https://helm.sh/docs/helm/helm_history/

## 验收标准

```sh
helm list -n cka-helm
helm history reporting -n cka-helm
helm get values reporting -n cka-helm
kubectl -n cka-helm get deployment reporting
kubectl -n cka-helm get service reporting
```

预期 release 状态为 `deployed`，历史包含 revision 1 和 2，Deployment 为 `2/2`，镜像为 `nginx:1.27.5`，Service 端口为 8080。
