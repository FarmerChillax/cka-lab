# 第 18 题：创建并离线恢复 etcd 快照

**建议用时：** 22 分钟。**Context：** `kind-cka-lab`。**控制平面节点：** `cka-lab-control-plane`。

## 题目主干

为当前集群的 etcd 创建并验证备份：

1. 找到 `kube-system` 中由 kubeadm 管理的 etcd 静态 Pod；
2. 使用本地 HTTPS endpoint `https://127.0.0.1:2379` 及现有 etcd CA、server certificate 和 key；
3. 将快照保存到 etcd 容器内 `/var/lib/etcd/cka-snapshot.db`；
4. 使用 `etcdutl` 查看快照状态；
5. 将快照离线恢复到新目录 `/var/lib/etcd/cka-restore`；
6. 不得修改 `/var/lib/etcd/member`，不得修改静态 Pod manifest，也不得重启控制平面组件。

官方参考：

- https://kubernetes.io/docs/tasks/administer-cluster/configure-upgrade-etcd/
- https://etcd.io/docs/v3.7/op-guide/recovery/

## 验收标准

```sh
ETCD_POD=$(kubectl -n kube-system get pod -l component=etcd \
  -o jsonpath='{.items[0].metadata.name}')

kubectl -n kube-system exec "$ETCD_POD" -- \
  etcdutl snapshot status /var/lib/etcd/cka-snapshot.db -w table

kubectl -n kube-system exec "$ETCD_POD" -- \
  test -f /var/lib/etcd/cka-restore/member/snap/db
```

预期快照状态包含非零 revision 和 key 数量，第二条验证命令退出码为 0，集群 API 仍正常可用。
