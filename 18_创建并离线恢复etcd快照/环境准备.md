# 环境准备：创建并离线恢复 etcd 快照

本题需要 kind 的 kubeadm 控制平面和其中的 etcd 静态 Pod。若 `cka-lab` 不存在，在本目录执行：

```sh
kind create cluster --name cka-lab --config kind-config.yaml --wait 5m
```

准备标记资源并确认 etcd Pod：

```sh
kubectl config use-context kind-cka-lab
kubectl apply -f setup.yaml
kubectl -n kube-system get pods -l component=etcd
kubectl -n cka-etcd get configmap checkpoint
```

重复练习前，在确认 Pod 名称后删除本题指定的旧产物：

```sh
ETCD_POD=$(kubectl -n kube-system get pod -l component=etcd \
  -o jsonpath='{.items[0].metadata.name}')
kubectl -n kube-system exec "$ETCD_POD" -- \
  rm -rf /var/lib/etcd/cka-snapshot.db /var/lib/etcd/cka-restore
kubectl apply -f setup.yaml
```

上述清理只针对练习产物，不触碰活动数据目录 `/var/lib/etcd/member`。准备阶段不要创建快照。
