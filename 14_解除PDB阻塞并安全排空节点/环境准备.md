# 环境准备：解除 PDB 阻塞并安全排空节点

本题沿用 `cka-lab` 三节点集群。若集群不存在，在本目录执行：

```sh
kind create cluster --name cka-lab --config kind-config.yaml --wait 5m
```

重置并准备环境：

```sh
kubectl config use-context kind-cka-lab
kubectl uncordon cka-lab-worker2 2>/dev/null || true
kubectl delete namespace cka-maint --ignore-not-found
kubectl label node cka-lab-worker2 maintenance-target=true --overwrite
kubectl apply -f setup.yaml
kubectl -n cka-maint rollout status deployment/frontend
kubectl -n cka-maint get pods -o wide
```

Deployment 使用软节点亲和性，使初始 Pod 优先落在 `cka-lab-worker2`；排空后仍可调度到另一工作节点。开始答题前确认至少一个 `frontend` Pod 位于目标节点。若没有，可删除 Deployment 的 Pod 让调度器重新创建。

重复练习时先执行上述重置命令。准备阶段不要修改 PDB，也不要排空节点。
