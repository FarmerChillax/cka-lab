# 第 14 题：解除 PDB 阻塞并安全排空节点

**建议用时：** 18 分钟。**Context：** `kind-cka-lab`。**命名空间：** `cka-maint`。

## 题目主干

需要维护节点 `cka-lab-worker2`。Deployment `frontend` 有 3 个副本，但现有 PodDisruptionBudget 阻止了正常排空。

完成以下任务：

1. 保持 Deployment 副本数为 3，不得删除 PDB。
2. 调整 PDB，使维护期间最多允许 1 个副本不可用。
3. 使用 `kubectl drain` 安全排空 `cka-lab-worker2`，忽略 DaemonSet，并允许删除使用 `emptyDir` 的系统 Pod。
4. 排空完成后，`frontend` 的 3 个副本必须全部 Ready，且均不在目标节点上。
5. 保持目标节点为不可调度状态。

官方参考：

- https://kubernetes.io/docs/tasks/run-application/configure-pdb/
- https://kubernetes.io/docs/tasks/administer-cluster/safely-drain-node/

## 验收标准

```sh
kubectl get node cka-lab-worker2
kubectl -n cka-maint get pdb frontend
kubectl -n cka-maint get deployment frontend
kubectl -n cka-maint get pods -l app=frontend -o wide
```

预期节点显示 `SchedulingDisabled`，PDB 的 `ALLOWED DISRUPTIONS` 为 1，Deployment 为 `3/3`，并且所有业务 Pod 均已离开 `cka-lab-worker2`。
