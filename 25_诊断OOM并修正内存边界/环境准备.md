# 环境准备 · 诊断 OOM 并修正内存边界

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择 Docker、Podman 或 nerdctl。在仓库根目录进入本题目录，随后用下列命令创建集群。已有同名 kind 集群时可以跳过创建。

```sh
cd 25_诊断OOM并修正内存边界
kind create cluster --name cka-next --config kind-config.yaml --wait 5m
```

本目录的 [kind-config.yaml](kind-config.yaml) 定义节点布局。

用 [setup.yaml](setup.yaml) 建立初始资源，再核对初始状态。

```sh
kubectl config use-context kind-cka-next
kubectl --context kind-cka-next apply -f setup.yaml
kubectl -n cka-25 wait --for=create pod -l app=parser --timeout=60s
kubectl -n cka-25 wait --for=jsonpath='{.status.containerStatuses[0].lastState.terminated.reason}' pod -l app=parser --timeout=180s
kubectl -n cka-25 get pods -l app=parser
```

如需重练，先执行 `kubectl --context kind-cka-next delete namespace cka-25 --ignore-not-found --wait=true`，随后重新运行本页准备命令。该命名空间只用于本题。
