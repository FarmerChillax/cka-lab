# 第 25 题 · 解题思路

## 关键技术难点

Exit code 137 也可能来自其他 SIGKILL，应从 lastState 确认 OOMKilled。request 决定调度时预留的资源，limit 约束容器运行时可使用的内存。

## 解题顺序与答案详解

等容器重启一次后采集退出原因，再更新容器资源。

```sh
pod=$(kubectl -n cka-25 get pod -l app=parser -o jsonpath='{.items[0].metadata.name}')
kubectl -n cka-25 get pod "$pod" -o jsonpath='{.status.containerStatuses[0].lastState.terminated.reason}{"\n"}' > parser.reason
kubectl -n cka-25 set resources deploy/parser -c parser --requests=memory=128Mi --limits=memory=160Mi
kubectl -n cka-25 rollout status deploy/parser --timeout=120s
```

若结果文件为空，查看正在运行或首次退出时的 state，并等待进入下一次重启再读取 lastState。若新副本 Pending，检查节点的可分配内存和 FailedScheduling 事件。

对照[题面验收标准](题目.md)检查最终状态。
