# 第 27 题 · 解题思路

## 关键技术难点

两个 Pod 占用相同节点和 hostPort，调度器能够识别冲突。若高优先级 Pod 允许抢占，调度器就可能淘汰占位 Pod。用专用优先级类避免影响其他工作负载。

## 解题顺序与答案详解

应用以下两个对象。先记录 Pending 与 FailedScheduling，再手动释放端口。

```yaml
apiVersion: scheduling.k8s.io/v1
kind: PriorityClass
metadata: {name: cka-27-batch}
value: 10000
globalDefault: false
preemptionPolicy: Never
---
apiVersion: v1
kind: Pod
metadata: {name: queued, namespace: cka-27}
spec:
  priorityClassName: cka-27-batch
  nodeSelector:
    kubernetes.io/hostname: cka-next-worker2
  containers:
  - name: app
    image: nginx:1.27.5
    ports:
    - {containerPort: 80, hostPort: 19027}
```

```sh
kubectl -n cka-27 wait --for=condition=PodScheduled=False pod/queued --timeout=60s
kubectl -n cka-27 describe pod queued | tee queued.pending.txt
kubectl -n cka-27 get pods -o wide
kubectl -n cka-27 scale deploy/resident --replicas=0
kubectl -n cka-27 wait --for=condition=Ready pod/queued --timeout=180s
```

若仍 Pending，检查 resident 的 Pod 是否还在 Terminating，或节点上是否另有 Pod 使用端口 19027。

对照[题面验收标准](题目.md)检查最终状态。
