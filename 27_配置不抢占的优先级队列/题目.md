# 第 27 题 · 配置不抢占的优先级队列

建议用时 19 分钟，环境准备完成后开始计时。

操作入口 `kubectl config use-context kind-cka-next`。Context 为 `kind-cka-next`，命名空间为 `cka-27`。

## 题目主干

创建名为 `cka-27-batch`、数值为 10000 的非默认 PriorityClass。高优先级任务必须等待资源释放。创建 Pod `queued`，使用 `nginx:1.27.5`，限制在 `cka-next-worker2`，声明容器端口 80、hostPort 19027 并使用新优先级类。保持 `resident` 运行并记录 queued 的 Pending 状态，随后把 resident 缩为 0，等待 queued Ready。

## 官方参考

- [Pod Priority and Preemption](https://kubernetes.io/docs/concepts/scheduling-eviction/pod-priority-preemption/) · PriorityClass 和 Never 抢占策略。

## 验收标准

```sh
cat queued.pending.txt
kubectl get priorityclass cka-27-batch -o yaml
kubectl -n cka-27 get deploy resident
kubectl -n cka-27 get pod queued -o wide
```

PriorityClass 不作为全局默认且不会抢占。`queued.pending.txt` 记录释放端口前的 Pending 状态和调度事件。释放后 queued 在 worker2 上 Ready。
