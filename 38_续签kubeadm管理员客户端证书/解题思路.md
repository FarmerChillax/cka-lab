# 第 38 题 · 解题思路

## 关键技术难点

`admin.conf` 将客户端证书与密钥嵌入 kubeconfig。续签在 kubeadm 控制平面节点进行，应选择单项子命令。kubectl 下次发请求时会重新读取配置，因此无需重启静态 Pod。

## 解题思路与答案详解

先查有效期和老证书。指纹命令只提取公有证书字段，完整 kubeconfig 留在节点内。

```sh
podman exec cka-pki38-control-plane kubeadm certs check-expiration
podman exec cka-pki38-control-plane kubectl --kubeconfig=/etc/kubernetes/admin.conf \
  config view --raw --minify -o jsonpath='{.users[0].user.client-certificate-data}' \
  | openssl base64 -d -A | openssl x509 -noout -sha256 -fingerprint -enddate -subject -issuer
podman exec cka-pki38-control-plane sh -ec \
  'test ! -e /etc/kubernetes/admin.conf.cka38.backup; cp -p /etc/kubernetes/admin.conf /etc/kubernetes/admin.conf.cka38.backup'
```

确认备份成功后续签并核对。

```sh
podman exec cka-pki38-control-plane kubeadm certs renew admin.conf
podman exec cka-pki38-control-plane kubectl --kubeconfig=/etc/kubernetes/admin.conf \
  config view --raw --minify -o jsonpath='{.users[0].user.client-certificate-data}' \
  | openssl base64 -d -A | openssl x509 -noout -sha256 -fingerprint -enddate -subject -issuer
podman exec cka-pki38-control-plane kubectl --kubeconfig=/etc/kubernetes/admin.conf \
  -n cka-38 get configmap checkpoint -o jsonpath='{.data.marker}{"\n"}'
```

指纹变化且检查对象可读，说明客户端证书已更新并可使用。若 kubeadm 报告 external CA，检查是否使用了本题的 kind 集群以及节点的签发条件。
