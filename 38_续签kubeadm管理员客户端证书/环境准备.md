# 环境准备 · 续签 kubeadm 管理员客户端证书

准备 kind v0.33.0 或更新版本、kubectl、OpenSSL 和已启动的容器运行时。kind 自动选择运行时。本题使用独立集群 `cka-pki38`。节点操作以 Podman 为例，若使用 Docker 或 nerdctl，替换节点操作中的运行时命令。

使用本目录的 [kind-config.yaml](kind-config.yaml) 和 [setup.yaml](setup.yaml) 准备环境。

```sh
cd 38_续签kubeadm管理员客户端证书
kind create cluster --name cka-pki38 --config kind-config.yaml --wait 5m
```

```sh
kubectl config use-context kind-cka-pki38
kubectl --context kind-cka-pki38 apply -f setup.yaml
kind get nodes --name cka-pki38
podman exec cka-pki38-control-plane test -f /etc/kubernetes/admin.conf
kubectl -n cka-38 get configmap checkpoint
```

已有同名且未续签的练习集群时可以跳过创建。重练前用 `kind delete cluster --name cka-pki38` 删除本题独立集群，再重新准备，以恢复原证书和清除上次的备份。
