# 第 38 题 · 续签 kubeadm 管理员客户端证书

建议用时 22 分钟。准备完成后开始计时。

操作入口 `kubectl config use-context kind-cka-pki38`，命名空间 `cka-38`，节点容器 `cka-pki38-control-plane`。

## 题目主干

在控制平面节点演练管理员客户端证书续签。先确认 `admin.conf` 当前的有效期，记录其中客户端证书的 SHA-256 指纹，并把原配置保存在节点内的 `/etc/kubernetes/admin.conf.cka38.backup`。仅续签 `/etc/kubernetes/admin.conf` 的客户端证书，保留原 CA、API 地址和证书身份。不得修改主机 kubeconfig 或其他控制平面证书，也不得重启组件。

## 官方参考

- [Certificate Management with kubeadm](https://kubernetes.io/docs/tasks/administer-cluster/kubeadm/kubeadm-certs/) · 证书有效期检查与单项续签。

## 验收标准

用节点内的新配置发起真实 API 请求。

```sh
podman exec cka-pki38-control-plane kubectl --kubeconfig=/etc/kubernetes/admin.conf \
  -n cka-38 get configmap checkpoint -o jsonpath='{.data.marker}{"\n"}'
```

输出 `client-cert-ok`。比较备份与续签后的证书，确认指纹变化、主体和签发方相同。备份只保存在控制平面节点内。
