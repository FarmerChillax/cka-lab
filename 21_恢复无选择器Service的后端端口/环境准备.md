# 环境准备 · 恢复无选择器 Service 的后端端口

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择 Docker、Podman 或 nerdctl。在仓库根目录进入本题目录，随后用下列命令创建集群。已有同名 kind 集群时可以跳过创建。

```sh
cd 21_恢复无选择器Service的后端端口
kind create cluster --name cka-next --config kind-config.yaml --wait 5m
```

本目录的 [kind-config.yaml](kind-config.yaml) 定义节点布局。

用 [setup.yaml](setup.yaml) 建立初始资源，再核对初始状态。

```sh
kubectl config use-context kind-cka-next
kubectl --context kind-cka-next apply -f setup.yaml
kubectl -n cka-21 rollout status deploy/legacy --timeout=120s
kubectl -n cka-21 wait --for=condition=Ready pod/probe --timeout=120s
legacy_ip=$(kubectl -n cka-21 get pod -l app=legacy -o jsonpath='{.items[0].status.podIP}')
kubectl -n cka-21 patch endpointslice legacy-manual --type=json -p="[{\"op\":\"replace\",\"path\":\"/endpoints/0/addresses/0\",\"value\":\"$legacy_ip\"}]"
kubectl -n cka-21 get endpointslice legacy-manual -o wide
```

如需重练，先执行 `kubectl --context kind-cka-next delete namespace cka-21 --ignore-not-found --wait=true`，随后重新运行本页准备命令。该命名空间只用于本题。
