# 第 21 题 · 恢复无选择器 Service 的后端端口

建议用时 14 分钟，环境准备完成后开始计时。

操作入口 `kubectl config use-context kind-cka-next`。Context 为 `kind-cka-next`，命名空间为 `cka-21`。

## 题目主干

遗留后端 `legacy` 正常监听 TCP 80，但客户端访问 `legacy-bridge:8080` 失败。修复手工维护的 EndpointSlice `legacy-manual`。保持后端 Pod、Service ClusterIP、端口和无 selector 的设计。

## 官方参考

- [Service](https://kubernetes.io/docs/concepts/services-networking/service/#services-without-selectors) · 无 selector 的服务。
- [EndpointSlices](https://kubernetes.io/docs/concepts/services-networking/endpoint-slices/) · 端口、就绪状态和 Service 关联。

## 验收标准

```sh
kubectl -n cka-21 get svc legacy-bridge -o yaml
kubectl -n cka-21 get endpointslice legacy-manual -o yaml
kubectl -n cka-21 exec probe -- wget -qO- -T 4 http://legacy-bridge:8080/
```

最后一条返回 Nginx 首页。Slice 保持指向准备阶段登记的 Pod IP。
