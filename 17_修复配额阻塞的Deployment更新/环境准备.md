# 环境准备：修复配额阻塞的 Deployment 更新

本题沿用 `cka-lab` 集群。若集群不存在，在本目录执行：

```sh
kind create cluster --name cka-lab --config kind-config.yaml --wait 5m
```

重建本题命名空间：

```sh
kubectl config use-context kind-cka-lab
kubectl delete namespace cka-quota --ignore-not-found
kubectl apply -f setup.yaml
kubectl -n cka-quota get resourcequota,limitrange,deployment,pods
kubectl -n cka-quota describe replicaset
```

资源配额会故意阻止部分 Pod 创建，因此准备命令不要求 Deployment Ready。开始前应看到 Deployment 期望 3 个副本，但实际 Ready 少于 3，并在 ReplicaSet 事件中看到 quota exceeded。
