# 第 19 题 · 解题思路

## 关键技术难点

同一个 `from` 元素中的命名空间与 Pod selector 取交集。拆成两个元素会取并集。验证时须同时观测允许和拒绝的请求。

## 解题顺序与答案详解

将以下 YAML 保存到临时文件 `ledger-policy.yaml`，在练习集群应用。

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata: {name: ledger-ingress, namespace: cka-19}
spec:
  podSelector:
    matchLabels: {app: ledger}
  policyTypes: [Ingress]
  ingress:
  - from:
    - namespaceSelector:
        matchLabels: {access-zone: trusted}
      podSelector:
        matchLabels: {role: reader}
    ports:
    - {protocol: TCP, port: 80}
```

```sh
kubectl --context kind-cka-next apply -f ledger-policy.yaml
```

若拒绝项仍能访问，核对 CNI、其他可能放行的策略与两个 selector 的缩进。

对照[题面验收标准](题目.md)检查最终状态。
