# 环境准备 · 隔离跨命名空间服务流量

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择 Docker、Podman 或 nerdctl。在仓库根目录进入本题目录，随后用下列命令创建集群。已有同名 kind 集群时可以跳过创建。

```sh
cd 19_隔离跨命名空间服务流量
kind create cluster --name cka-next --config kind-config.yaml --wait 5m
```

本目录的 [kind-config.yaml](kind-config.yaml) 定义节点布局。

用 [setup.yaml](setup.yaml) 建立初始资源，再核对初始状态。

```sh
kubectl config use-context kind-cka-next
kubectl --context kind-cka-next apply -f setup.yaml
kubectl -n cka-19 rollout status deploy/ledger --timeout=120s
kubectl -n cka-19 wait --for=condition=Ready pod/wrong-namespace --timeout=120s
kubectl -n cka-19-client wait --for=condition=Ready pod/allowed pod/wrong-role --timeout=120s
kubectl -n cka-19-client exec allowed -- wget -qO- -T 4 http://ledger.cka-19.svc.cluster.local/
```

重练时在 `kind-cka-next` 删除本题的两个命名空间 `cka-19` 和 `cka-19-client`，再重新准备。
