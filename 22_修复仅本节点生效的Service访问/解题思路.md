# 第 22 题 · 解题思路

## 关键技术难点

即使 EndpointSlice 中有就绪端点，代理也可能在没有本地后端的节点上拒绝 Service 流量。

## 解题顺序与答案详解

对照两个客户端的 NODE 和 Slice 的 nodeName。保留调度规则，让 Service 使用所有节点上的就绪端点。

```sh
kubectl -n cka-22 get endpointslice -l kubernetes.io/service-name=inventory -o yaml
kubectl -n cka-22 get svc inventory -o yaml
kubectl -n cka-22 patch svc inventory --type=merge -p '{"spec":{"internalTrafficPolicy":"Cluster"}}'
```

若两端都失败，先检查后端是否 Ready，并区分 DNS 失败和 HTTP 失败。

对照[题面验收标准](题目.md)检查最终状态。
