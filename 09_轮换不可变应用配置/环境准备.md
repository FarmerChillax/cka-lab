# 环境准备：轮换不可变应用配置

需要 `kind` v0.33.0 或更新版本、`kubectl` 和已启动的 kind 兼容容器运行时。kind 自动选择可用运行时。本题沿用 `cka-lab` 集群；已有集群时跳过创建。

```sh
cd 09_轮换不可变应用配置
kind create cluster --name cka-lab --config kind-config.yaml --wait 5m  # 仅在集群不存在时执行
kubectl config use-context kind-cka-lab
kubectl apply -f setup.yaml
kubectl -n cka-config rollout status deployment/report-api --timeout=120s
```

确认初始版本均为不可变对象，且 Deployment 正在引用 v1：

```sh
kubectl -n cka-config get cm report-config-v1 -o jsonpath='{.immutable}{"\n"}'
kubectl -n cka-config get secret report-credentials-v1 -o jsonpath='{.immutable}{"\n"}'
kubectl -n cka-config get deploy report-api -o yaml | grep 'report-.*-v1'
```

从此处开始 18 分钟计时。重练时删除命名空间并重新应用初始配置：

```sh
kubectl config use-context kind-cka-lab
kubectl delete namespace cka-config --ignore-not-found --wait=true
kubectl apply -f setup.yaml
```
