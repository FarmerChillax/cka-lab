# 第 9 题：轮换不可变应用配置

**建议用时：** 18 分钟。**Context：** `kind-cka-lab`。**命名空间：** `cka-config`。

**操作入口：** `kubectl config use-context kind-cka-lab`

## 题目主干

`Deployment/report-api` 使用不可变的 ConfigMap 和 Secret。请在不删除 v1 对象、不把凭据明文写入 Pod template 的前提下完成配置轮换：

1. 创建不可变 `ConfigMap/report-config-v2`，键 `app.properties` 的内容必须是两行：`MODE=production` 与 `REPORT_PATH=/srv/reports`。
2. 创建不可变 `Secret/report-credentials-v2`，键 `username` 为 `reporter-v2`，键 `password` 为 `cka-rotate-2026`。
3. 更新 `report-api`，让环境变量 `DB_USERNAME`、`DB_PASSWORD` 分别通过 `secretKeyRef` 引用 v2 的两个键；投射卷也必须改用两个 v2 对象。
4. 投射后的 `app.properties`、`credentials/username`、`credentials/password` 文件权限必须为 `0400`。完成滚动更新并保持 2 个副本可用。

官方参考：[ConfigMaps](https://kubernetes.io/docs/concepts/configuration/configmap/) 的不可变配置、[Secrets](https://kubernetes.io/docs/concepts/configuration/secret/) 的引用方式，以及 [Projected Volumes](https://kubernetes.io/docs/concepts/storage/projected-volumes/) 的来源组合。

## 验收标准

```sh
kubectl -n cka-config rollout status deployment/report-api --timeout=120s
POD=$(kubectl -n cka-config get pod -l app=report-api -o jsonpath='{.items[0].metadata.name}')
kubectl -n cka-config exec "$POD" -- sh -c 'printf "%s %s\n" "$DB_USERNAME" "$DB_PASSWORD"; cat /etc/report/app.properties; stat -c "%a %n" /etc/report/app.properties /etc/report/credentials/username /etc/report/credentials/password'
kubectl -n cka-config get cm report-config-v2 -o jsonpath='{.immutable}{"\n"}'
kubectl -n cka-config get secret report-credentials-v2 -o jsonpath='{.immutable}{"\n"}'
```

输出应显示新凭据、新配置、三个文件权限均为 `400`，最后两条命令均输出 `true`。
