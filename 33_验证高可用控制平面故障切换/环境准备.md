# 环境准备 · 验证高可用控制平面故障切换

准备 kind v0.33.0 或更新版本、kubectl 和已启动的容器运行时。kind 自动选择 Docker、Podman 或 nerdctl。在仓库根目录进入本题目录，随后用下列命令创建集群。已有同名 kind 集群时可以跳过创建。

```sh
cd 33_验证高可用控制平面故障切换
kind create cluster --name cka-ha --config kind-config.yaml --wait 5m
```

本目录的 [kind-config.yaml](kind-config.yaml) 定义节点布局。本题创建 3 个控制平面和 1 个工作节点。建议先为容器运行时留出至少 8 GiB 可用内存。节点操作以 Podman 为例，kind 若选用 Docker 或 nerdctl，则替换为对应 CLI。

用 [setup.yaml](setup.yaml) 建立初始资源，再核对初始状态。

```sh
kubectl config use-context kind-cka-ha
kubectl --context kind-cka-ha apply -f setup.yaml
kubectl wait --for=condition=Ready node --all --timeout=120s
kubectl -n kube-system wait --for=condition=Ready pod -l component=etcd --timeout=150s
kubectl get nodes
kubectl -n kube-system get pods -l component=etcd -o wide
```

重练时在三个控制平面节点容器均运行的情况下应用 setup.yaml，重置 checkpoint 数据。也可在练习完之后删除独立集群 `kind delete cluster --name cka-ha`。
